# Power BI Portfolio

This repository contains my Power BI portfolio projects.

## Portfolio Projects

Use this structure for each dashboard/report you add:

### 1) Project Name
- **Goal:** What business problem does this solve?
- **Dataset:** Source and size of the data
- **Tools:** Power BI, Power Query, DAX, etc.
- **Highlights:** Key KPIs, visuals, and insights
- **File:** `path/to/project.pbix`
- **Preview:** Add screenshots/GIFs in this repo and link them here

## Suggested Repository Structure

```text
Portfolio_BI/
├─ dashboards/
│  ├─ project-1/
│  │  ├─ project-1.pbix
│  │  ├─ README.md
│  │  └─ assets/
│  │     └─ preview.png
├─ datasets/
│  └─ sample-data.csv
└─ README.md
```
